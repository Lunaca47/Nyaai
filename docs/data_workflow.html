1. Hybrid Retrieval & Grounding

1,705 substantive statutory provisions indexed with BM25 Okapi + dense vector embeddings (all-MiniLM-L6-v2) fused via RRF (k=60).

2. Deterministic Verification Gate

Strict 5-verdict CitationVerifier hard gate prevents hallucinations, blocks ungrounded citations, and flags repealed pre-2024 acts.

3. Encrypted Matter Management

Client-side AES-GCM-256 encrypted matters with chronological timelines, evidence preservation checklists, and offline SQLite fallback.
